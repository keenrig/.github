<h2 align="center">Hi there, this is Keenrig 👋</h2>

<p align="center"><b>Self-host n8n, Activepieces and more — set up in 5 minutes</b></p>

Keenrig turns a blank Linux VPS into your own app server. Run one command, open the Admin on your
server's IP, and install apps from the catalog with one click each — their database, domain, HTTPS
certificate and backups are set up with them. Your server, your data: the optional cloud Console can be
disconnected and everything keeps running.

- **[Keenrig](https://github.com/keenrig/keenrig)** — the box, installer and app catalog (AGPL-3.0), with the quick start
- **[Install guide](https://keenrig.com/en/docs/install)** — from a blank VPS to your first app
- **[keenrig.com](https://keenrig.com)** — product, pricing and the free tier
- **[Contributing](https://github.com/keenrig/keenrig/blob/main/CONTRIBUTING.md)** — add an app to the catalog or fix a bug

### What's inside

- **App catalog** — n8n, Activepieces, Open WebUI and more, each pinned to an exact image digest
- **Domains & HTTPS** — start on your server's IP; add your own domain, or a free `*.keenrig.com` name through the optional Console, later
- **Backups** — encrypted backups to a server folder, a NAS or your own S3 (scheduling in progress)
- **Cloud optional** — pair with Keenrig Console for remote management, or never connect it; your apps run either way

```sh
curl -fsSL https://get.keenrig.com | sudo sh
```
